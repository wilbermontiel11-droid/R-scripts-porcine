# R-scripts-porcine

This repository contains R scripts and datasets designed to support gene-based functional and enrichment analyses. To run the scripts, users must set the R working directory to the folder containing the downloaded files. Input data should be provided in CSV format, and users must modify or specify the gene symbols or gene IDs according to their study species and research objectives.

The workflow includes data preprocessing, filtering of significant terms, and visualization of Gene Ontology (GO) enrichment results by category (Biological Process, Molecular Function, and Cellular Component). Users may adapt the scripts to analyze their own gene lists or to replicate the enrichment analysis presented in this study. All steps are fully reproducible, and output files are automatically generated and saved for downstream analysis or inclusion as supplementary material.
